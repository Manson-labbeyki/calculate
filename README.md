# محاسبه هزینه چاپ

## نسخه‌ها
- `specialist.html` — نسخه کاربر تخصصی (بانک متریال، محاسبات داخلی/جلد/راهنما/گلاسه، جمع نهایی)
- `index.html` — نسخه کاربر فروش / غیرتخصصی (سفارش ساده + تنظیمات پشت‌صحنه)

نسخه تخصصی: گرد کردن قیمت به بالا، حذف صحافی/حمل از بانک، حالت قیمت کل/روی هر جلد، قیمت نرم‌افزار، تب‌های چسبان.
